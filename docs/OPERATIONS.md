# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 对账无差异且无坏行时可签发。对仍有差异的版本可填写暂缓意见。
5. 导出复核证据并保存于交接记录。

## 补偿抵扣月结

1. 在输入样例选择“补偿 · 可签发样例”或上传补偿 CSV。
2. 查看“抵扣计算”：有回执的补偿进入收入冲减，无回执但未到期的留在客户余额，本月失效的在本期了结。
3. 查看“余额判定”：失效仍挂余额、回执倒挂、跨期回执会阻止签发；有这些差异时填写暂缓意见并退回业务处理。
4. 对账通过后签发，冲减与了结记入补偿台账。后续批次会自动跳过已入账补偿，重复执行不会二次冲减。
5. 用 `GET /api/ledger` 或证据文件核对跨批次的冲减与了结合计。

补偿字段、处理口径与拒签条件见 [补偿抵扣](COMPENSATION.md)。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次和补偿台账。恢复时使用原 Docker Compose 数据卷。
